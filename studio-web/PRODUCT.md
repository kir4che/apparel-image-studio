# Product

## Platform
web

## Stack
Existing local Python + Pillow runtime; plain HTML/CSS/JavaScript for the approved small local tool. No framework, account, database, deployment or remote assets.

## Users
The user's sister prepares clothing product photographs for Shopee on this Mac.

## Product Purpose
The user selects two photographs; the program joins them without manually resizing or aligning each one. The user explicitly approved this workflow in the preceding conversation.

## Capabilities and Constraints
Import one product folder, choose two images, create multiple pairs, swap sides, freely crop all four edges, crop a single photo independently, remove a pair or photo, preview and export. Studio is the default photo-library mode; single-photo crop updates the thumbnail, current draft, saved pairs and standalone export. Start from the full source-photo bounds, then let the user adjust any edge; preserve source pixels during the merge. Never overwrite original files. Local loopback only. Do not read or apply model crop suggestions. The workbench keeps source dimensions without an output-size cap. JPG exports use high quality without a 2 MB limit. No auto selection, copywriting or publishing.

## Evidence on Hand
23 source photos in the user-provided 原圖 folder, including one exact duplicate. Earlier local crop reports and the one approved-direction sample. No fabricated brand assets or commercial claims.

## Product Principles
Images lead; controls explain their effect. Studio is a human choice. Cropping and canvas padding are separate. Show what will be exported. Keep every source and export traceable.
